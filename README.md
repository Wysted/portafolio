# Portafolio

Portafolio de Vladimir Besser, con estilo de web personal japonesa de los años 2000 (Astro 5 + Tailwind 4).

- `yarn dev`: servidor de desarrollo en `localhost:4321`.
- `yarn build`: genera el sitio en `./dist/`.
- Se despliega solo en Vercel con cada push a `main`.
- La especificación visual está en [DESIGN.md](DESIGN.md).
